I made this personal portfolio for me, it has tons of easter eggs and it has a split personality:

This means there is both a profesional portfolio and an "hacker" portfolio where you are shown a terminal with different buttons as options to do various stuff (inspired by Blooket Crypto hack)


While Mobile browser is supported for the normal site, for the hacker redirect PC IS HEAVLY RECCOMENDED OR ELSE WIDTHS START TO GLITCH.

This project has really been a learning journey for me, I learned how to web dev for the first time, how to use react, tailwind css, how to code in css, jsx, html, you name it. the most key thing I learned is to make embed stuff USE <A> TAGS. 

I had to publish and deploy this at an airport with internet explorer as my browser which was PURE PAIN. ON TOP IF THAT MY phone couldn't load more than one app at a time so switching to test the deploy wasn't a very time efficent optionat all.

Really proud of how this website turned out I basically went from zero to somewhat hero!

how to deploy:
put everything into a git repo 
host on netlify
change homepage to "your site link" on package.json

Enjoy!
